# Asymptotic constant for the off-diagonal Ramsey numbers $R(3,k)$

## Description of constant

Let $R(3,k)$ be the smallest integer $n$ such that every red/blue colouring of the edges of the complete graph $K\_n$ contains a red triangle or a blue $K\_k$. Equivalently, $R(3,k)-1$ is the largest number of vertices of a triangle-free graph with independence number less than $k$. It is known that $R(3,k)$ has order of magnitude $k^2/\log k$ [AKS1980], [Kim1995]. Define

$$C_{17b} := \lim_{k \to \infty} \frac{R(3,k)}{k^2/\log k},$$

if the limit exists, where $\log$ is the natural logarithm.

## Known upper bounds

| Bound | Reference | Comments |
| ----- | --------- | -------- |
| $<\infty$ | [AKS1980] | First upper bound of the correct order $O(k^2/\log k)$ |
| $1$ | [She1983] | Via Shearer's lower bound on the independence number of triangle-free graphs in terms of the average degree |

## Known lower bounds

| Bound | Reference | Comments |
| ----- | --------- | -------- |
| $0$ | [Erd1961] | Proves $R(3,k) \geq c k^2/\log^2 k$, one logarithm short of the correct order |
| $>0$ | [Kim1995] | First lower bound of the correct order $\Omega(k^2/\log k)$, via a semi-random construction |
| $\frac{1}{4}$ | [BK2021], [FGM2020] | Independent analyses of the triangle-free process (preprints from 2013) |
| $\frac{1}{3}$ | [CJMS2025] | Also disproves the conjecture of [FGM2020] that $\frac{1}{4}$ is sharp |
| $\frac{1}{2}$ | [HHKP2025] | |

## Additional comments and links

- The existence of the limit is open. For the purposes of this page, upper (resp. lower) bounds on $C\_{17b}$ should be interpreted as bounding the limit superior (resp. limit inferior).
- Determining $C\_{17b}$ is [Erdős problem #165](https://www.erdosproblems.com/165).
- The value $\frac{1}{2}$ has been conjectured to be the correct constant by several groups; see [CJMS2025] and [HHKP2025].
- See [$C\_{17}$](https://teorth.github.io/optimizationproblems/constants/17a.html) for the diagonal Ramsey numbers.
- Small values. Exact values of $R(3,k)$ are known only for $k \leq 9$; see the dynamic survey [Rad] for the current small-$k$ bounds. Recent computer searches over circulant graphs give improved lower bounds for $24 \leq k \leq 49$ [CFLSTT2026], and a circulant graph on $\mathbb{Z}\_{240}$ gives $R(3,33) \geq 241$ [SK2026]. Bounds for individual small $k$ do not bear directly on $C\_{17b}$.
