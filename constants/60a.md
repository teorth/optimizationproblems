# Favard-length decay exponent

## Description of constant

Let $E\subset \mathbb{R}^2$ be a planar set. The **Favard length** of $E$ is defined by

$$
\mathrm{Fav}(E)\ :=\ \frac{1}{\pi}\int_0^\pi \lvert \mathrm{Proj}\,R_\theta E\rvert\, d\theta,
$$

where $\mathrm{Proj}$ is orthogonal projection to the horizontal axis and $R_\theta$ is rotation by angle $\theta$.
<a href="#NPV2011-def-fav">[NPV2011-def-fav]</a>

The Favard length has the following probabilistic interpretation: up to a constant factor, $\mathrm{Fav}(E)$ is the probability that a “Buffon’s needle” (a long line segment dropped at random) hits $E$.
<a href="#NPV2011-buffon-interpretation">[NPV2011-buffon-interpretation]</a>

Let $C_n$ be the $n$-th stage in the construction of the middle-half Cantor set, and let

$$
K_n\ :=\ C_n \times C_n.
$$

Then $K_n$ is a union of $4^n$ axis-parallel squares of side length $4^{-n}$.
<a href="#NPV2011-Kn-4n-squares">[NPV2011-Kn-4n-squares]</a>

A classical theorem of Besicovitch implies that $\mathrm{Fav}(K_n)\to 0$ as $n\to\infty$, and it remains open to determine the exact rate of decay.
<a href="#NPV2011-besicovitch-open-decay">[NPV2011-besicovitch-open-decay]</a>

We define the **Favard-length decay exponent** $\alpha_{\mathrm{Fav}}$ by

$$
C_{60}\ :=\ \alpha_{\mathrm{Fav}}\ :=\ \sup\Bigl\{\alpha\ge 0:\ \exists C>0\ \text{such that}\ \mathrm{Fav}(K_n)\le C\,n^{-\alpha}\ \text{for all}\ n\in\mathbb{N}\Bigr\}.
$$

The best established range currently is

$$
\frac{1}{6}\ \le\ \alpha_{\mathrm{Fav}}\ \le\ 1.
$$

<a href="#NPV2011-thm1-powerlaw">[NPV2011-thm1-powerlaw]</a> <a href="#BV2010-thm1-lb-logn-over-n">[BV2010-thm1-lb-logn-over-n]</a>

## Known upper bounds

| Bound | Reference | Comments |
| ----- | --------- | -------- |
| $1$ | <a href="#BV2010">[BV2010]</a> | Bateman–Volberg prove $\mathrm{Fav}(K_n)\ge c\,\frac{\log n}{n}$, which rules out any estimate $\mathrm{Fav}(K_n)\le C n^{-\alpha}$ with $\alpha>1$. <a href="#BV2010-thm1-lb-logn-over-n">[BV2010-thm1-lb-logn-over-n]</a> |

## Known lower bounds

| Bound | Reference | Comments |
| ----- | --------- | -------- |
| $0$ |  | Trivial (since $\mathrm{Fav}(K_n)$ is uniformly bounded). |
| $1/6$ | <a href="#NPV2011">[NPV2011]</a> | Nazarov–Peres–Volberg prove $\mathrm{Fav}(K_n)\le C n^{-1/6+\delta}$ (equivalently, $\mathrm{Fav}(K_n)\le C n^{\delta-1/6}$) for every $\delta>0$. <a href="#NPV2011-thm1-powerlaw">[NPV2011-thm1-powerlaw]</a> |
| $1/5$ | <a href="#Mar2026">[Mar2026]</a> | Marshall replaces the Nazarov&ndash;Peres&ndash;Volberg combinatorial propagation with a sharper one (v2, section 7), giving $\mathrm{Fav}(K\_n)\le C\_u n^{-1/5+u}$ for every $u>0$ (Theorem 1.2, restated as Theorem 8.3). arXiv preprint, not refereed. <a href="#Mar2026-thm82">[Mar2026-thm82]</a> |
| $1/4$ | <a href="#Lin2026">[Lin2026]</a> | A Lean 4 formalization of $\mathrm{Fav}(K\_n)\le C\_a n^{-a}$ for every $a<1/4$, hence $\alpha\_{\mathrm{Fav}}\ge 1/4$. It uses an endpoint form of Marshall's marked-cylinder dichotomy (v2, section 7) together with a joint negative moment of the low-frequency product, which supplies the kind of weighted low-frequency input that Marshall's section 8.5 identifies as missing for $1/4$. Registered on the Palomar registry; not refereed. <a href="#Lin2026-statements">[Lin2026-statements]</a> |

## Additional comments and links

- **Prior explicit upper bound.** Before the power-law bound, the only explicit upper bound recorded in this literature was of iterated-log type, $\exp(-c\,\log_* n)$, attributed to Peres–Solomyak.
  <a href="#NPV2011-exp-logstar">[NPV2011-exp-logstar]</a>

- **Non-optimality and a method barrier.** Nazarov–Peres–Volberg remark that the exponent $1/6$ is not optimal, but that decay faster than $O(n^{-1/4})$ would require new ideas (relative to their methods).
  <a href="#NPV2011-remark-n-1-4">[NPV2011-remark-n-1-4]</a>

- **A withdrawn earlier claim of $1/4$.** Version 1 of <a href="#Mar2026">[Mar2026]</a> (2 September 2025, then titled *Power laws for the Favard length problem in $\mathbb{R}^d$*) asserted the exponent $1/4$ for this set in its Remark 1.3 and section 3.5. Version 2 withdraws that assertion. <a href="#Mar2026-withdrawal">[Mar2026-withdrawal]</a>

- [Wikipedia page on Favard length](https://en.wikipedia.org/wiki/Favard_length)
