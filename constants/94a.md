# Online bin packing asymptotic competitive ratio

## Description of constant

In classic one-dimensional online bin packing, a sequence $I = (s\_1, \dots, s\_n)$ of items of sizes in $(0, 1]$ arrives one by one and must be assigned irrevocably to unit-capacity bins without exceeding total size $1$ in any bin. For a deterministic online algorithm $A$, let $A(I)$ denote the number of bins used on instance $I$ and $\mathrm{OPT}(I)$ denote the offline minimum number of bins. The asymptotic competitive ratio of $A$ is

$$R_\infty(A) := \limsup_{k \to \infty} \sup_{\mathrm{OPT}(I) = k} \frac{A(I)}{k},$$

equivalently $\inf\{R > 0 : \exists C \ge 0,\ \forall I,\ A(I) \le R\,\mathrm{OPT}(I) + C\}$. The constant $C\_{94} = R\_\infty$ is the infimum of $R\_\infty(A)$ over all deterministic online algorithms $A$.

| Bound | Reference | Comments |

## Additional comments

- For the **absolute** competitive ratio $\sup\_I A(I)/\mathrm{OPT}(I)$ (without additive constant), the exact optimal value is $5/3$ [BBDSvS2015].
- Heydrich and van Stee [HvS2016] proved a $1.5762$ lower floor for algorithms that color a fixed fraction of each type red and make packing decisions solely by type (corrected from $1.5766$ in [Mar2026], §7). Multi-container Advanced Harmonic with multiple tiny reservations and cutoff $1/160$ breaks past $1.5762$ to $1.571839305182$* [Kir2026].
