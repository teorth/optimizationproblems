# Bohnenblust--Hille constant on the Boolean cube

## Description of constant

Degree at most $d$ functions $f:\lbrace \pm 1\rbrace^n\to\mathbb{R}$ have Fourier--Walsh expansion

$$
f(x)=\sum_{S\subseteq [n], |S|\leq d} \widehat f(S) \ x^S,
\qquad
x^S:=\prod_{i\in S}x_i,
\qquad
[n]:=\lbrace 1,\dots,n\rbrace.
$$

For $d\in\mathbb{N}$ set $p_d:=\frac{2d}{d+1}$. The (degree $\le d$) Bohnenblust--Hille inequality asks for the smallest constant $C$ such that for every $n$ and every function $f:\lbrace \pm 1\rbrace^n\to\mathbb{R}$ of degree at most $d$  ($d\leq n$),  

$$
\left(\sum_{\substack{S\subseteq[n]\\ |S|\le d}} |\widehat f(S)|^{p_d}\right)^{1/p_d}
\le C \|f\|_\infty,
\qquad
\|f\|_{\infty}:=\max_{x\in \lbrace \pm 1\rbrace^n}|f(x)|.
$$

Let $\mathrm{BH}^{\le d}_{\lbrace\pm1\rbrace}$ denote this best constant $C$ (which depends on $d$). We define

$$
C_{26a}:=\sup_{d\ge 1}\mathrm{BH}^{\le d}_{\lbrace\pm1\rbrace}.
$$

Equivalently, $C_{26a}$ is the smallest constant for which the above inequality holds **simultaneously for all degrees** $d$ (with the exponent $p_d=\frac{2d}{d+1}$ depending on $d$ as above).

## Known upper bounds

| Bound | Reference | Comments |
| ----- | --------- | -------- |
| $\infty$ | Trivial | the best general estimate currently available is subexponential growth: $\mathrm{BH}^{\le d}_{\lbrace\pm1\rbrace}\le C^{\sqrt{d \ \log \, d}}$ for an absolute constant $C>1$ [DMP2019]. |

## Known lower bounds

| Bound | Reference | Comments |
| ----- | --------- | -------- |
| $2$ | [ADGP2025] | Degree $d$ address function achieves the bound $2^{\frac{d-1}{d}}$. At present, chasing incremental improvements of lower bounds seems less compelling than establishing any finite uniform upper bound. That said, exhibiting a construction that forces the constant to exceed $100$ would already be a genuinely interesting result. |

## Additional comments and links

- The exponent $p_d=\frac{2d}{d+1}$ is best possible (cannot be increased), even if the constant is allowed to depend on $d$. [Bl2001]
- The paper [DMP2019] proves the subexponential upper bound $\mathrm{BH}^{\le d}_{\lbrace\pm1\rbrace}\le C^{\sqrt{d\log d}}$ [arXiv:1706.03670](https://arxiv.org/abs/1706.03670)
- (Fixed degree.) The address function is not extremal at any fixed degree $d\ge 2$. For every $d\ge1$ there is an explicit $f_d:\lbrace\pm1\rbrace^{3d}\to\lbrace 0,\pm1\rbrace$ of degree $d$ with exactly $(2^d-1)2^d$ nonzero Fourier coefficients, all equal to $\pm 2^{-d}$, giving $\mathrm{BH}^{\le d}_{\lbrace\pm1\rbrace}\ge 2(1-2^{-d})^{\frac{d+1}{2d}}$ [Kos2026]. This exceeds $2^{\frac{d-1}{d}}$ for every $d\ge2$: for example $1.6118$ versus $1.4142$ at $d=2$, and $1.8296$ versus $1.5874$ at $d=3$. These values are still below $2$, so the lower bound for $C_{26a}$ is unchanged. Moreover every $\lbrace 0,\pm1\rbrace$-valued $f$ of degree $d$ has ratio at most $2\Pr[f\neq 0]^{\frac{d+1}{2d}}$, with equality for $f_d$ (and at most $2^{\frac{d-1}{d}}$ if $f$ is $\pm1$-valued [ADGP2025]), so beating $2$ needs other value sets. The proof is short, unrefereed and AI-assisted; the functions for $d\le 7$ are checked exactly.
- One application is to computational learning theory: quantitative bounds on the Bohnenblust--Hille constants for functions on $(\pm 1)^n$ yield improved **upper bounds on the randomized query complexity** for learning bounded degree-$d$ functions from random queries; see [EI2022].
