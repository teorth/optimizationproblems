# Classical zero-free region constant

## Description of constant

$C\_{8} = R$ is the least constant such that there are no zeroes $\sigma+it$ of the Riemann zeta function with $\lvert t \rvert \geq 2$ and $\sigma > 1 - \frac{1}{R \log \lvert t \rvert}$.

| $2/\log \gamma\_{1} \approx 0.755106$* | [[OAI2026](#OAI2026)], [[PT2021](#PT2021)] | Deduced from the $7/8$ quasi-Riemann hypothesis ([OAI2026], Theorem 1.1, which covers $\zeta$) and the verification of RH up to height $3\cdot 10^{12}$ ([PT2021]). A zero $\beta+i\gamma$ with $2 \le \lvert\gamma\rvert \le 3\cdot 10^{12}$ has $\beta = 1/2$, so it lies outside the region exactly when $R \ge 2/\log\lvert\gamma\rvert$, and the worst case is $\gamma\_{1}$. A zero with $\lvert\gamma\rvert > 3\cdot 10^{12}$ has $\beta \le 7/8$, so it lies outside when $R \ge 8/\log\lvert\gamma\rvert$, and $8/\log(3\cdot 10^{12}) < 0.279$. So $R = 2/\log\gamma\_{1}$ is admissible and matches the lower bound. RH up to height $\gamma\_{1}^{4} < 4\cdot 10^{4}$ already suffices. **The deduction is the contributing author's, not the source's:** [OAI2026] does not state a bound for $C\_{8}$, and this step has not been refereed. [OAI2026] is itself an unrefereed preprint; its $\zeta$ statement is formalized in Lean as [`OAI.riemannZeta_ne_zero_of_seven_eighths_lt_re`](https://github.com/openai/math/blob/adc7f1241b42e322a6451854ab7e4b4c146bf78a/lean/OAI/NumberTheory/DirichletL/Nonvanishing.lean); no verification-service registration is cited here. |

## Known lower bounds

| Bound | Reference | Comments |
| ----- | --------- | -------- |
| $2/\log \gamma\_{1} \approx 0.755106$ | - | Unconditional: $\gamma\_{1} = 14.1347\dots$ is the ordinate of the lowest zero of $\zeta$, and that zero has $\sigma = 1/2$, so any admissible $R$ must satisfy $1/2 \leq 1 - 1/(R\log\gamma\_{1})$. Optimal assuming RH, and matched by the upper bound deduced from [OAI2026]. |

## Additional comments and links

- This constant is relevant to the classical error term in the prime number theorem; in particular, $\pi(x) = \mathrm{Li}(x) + O\left(x \exp\left(-\sqrt{\log x / R}\right)\right)$.
