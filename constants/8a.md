# Classical zero-free region constant

## Description of constant

$C\_{8} = R$ is the least constant such that there are no zeroes $\sigma+it$ of the Riemann zeta function with $\lvert t \rvert \geq 2$ and $\sigma > 1 - \frac{1}{R \log \lvert t \rvert}$.

## Known lower bounds

| Bound | Reference | Comments |
| ----- | --------- | -------- |
| $2/\log \gamma\_{1} \approx 0.755106$ | - | Unconditional: $\gamma\_{1} = 14.1347\dots$ is the ordinate of the lowest zero of $\zeta$, and that zero has $\sigma = 1/2$, so any admissible $R$ must satisfy $1/2 \leq 1 - 1/(R\log\gamma\_{1})$. Optimal assuming RH. |

## Additional comments and links

- This constant is relevant to the classical error term in the prime number theorem; in particular, $\pi(x) = \mathrm{Li}(x) + O\left(x \exp\left(-\sqrt{\log x / R}\right)\right)$.
