# Univalent Bloch constant

## Description of constant

Let $\mathbb{D}=\\{z\in\mathbb{C}:\lvert z\rvert<1\\}$ and let $\mathcal{F}$ be the class of holomorphic functions $f:\mathbb{D}\to\mathbb{C}$ normalized by $f'(0)=1$. <a href="#BS2023-def-F">[BS2023-def-F]</a>

For $f\in\mathcal{F}$, let $B_f$ denote the radius of the largest univalent disk in $f(\mathbb{D})$. <a href="#BS2023-def-Bf">[BS2023-def-Bf]</a>

The **univalent Bloch constant** is
$$
B_u\ :=\ \inf\{B_f : f\in\mathcal{F},\ f\ \text{is univalent in }\mathbb{D}\}.
$$
<a href="#BS2023-def-Bu">[BS2023-def-Bu]</a>

We define
$$
C_{57c}\ :=\ B_u.
$$

Wikström proves the following bounds for this same constant in his 2026 arXiv preprint (Theorems 1.2 and 1.3):
$$
0.612242\ \leq\ C_{57c}\ <\ 0.6562681.
$$
<a href="#W2026">[W2026]</a> A subsequent candidate, unrefereed lower bound is $C\_{57c}\geq 6123/10000=0.61230^\*$; see <a href="#P2026">[P2026]</a> and the verification qualifications below.

Also, from $B\le B_l\le L\le B_u$ and $L>\frac{1}{2}+10^{-335}$, one gets the weaker bound $B_u>\frac{1}{2}+10^{-335}$. <a href="#BS2023-relations">[BS2023-relations]</a> <a href="#BS2023-bounds-L">[BS2023-bounds-L]</a>

## Known upper bounds

| Bound | Reference | Comments |
| ----- | --------- | -------- |
| $1$ | Trivial | The identity function $f(z)=z$ is univalent with $f'(0)=1$ and has $B_f=1$, hence $B_u\le 1$. |
| $0.658$ | <a href="#Rob1935">[Rob1935]</a> | Disc of radius about $2.956$ minus six radial slits ending at moduli $1$ and $2$. |
| $0.65647$ | <a href="#Good1945">[Good1945]</a> | Radial slits added in bisecting generations. |
| $0.6564155$ | <a href="#BH1985">[BH1985]</a> | Radial slits; third generation not bisecting. Numerical. |
| $0.6563937$ | <a href="#COC2009">[COC2009]</a> | Disc of radius $4.0546358$ minus six radial slits and six harmonically symmetric arcs; numerical evaluation of an explicit theta-function formula, stated correct to 10 decimal places. |
| $0.656319277272^\*$ | <a href="#OCP2010">[OCP2010]</a> | Disc of radius $5.1195152501$ minus six radial slits and further harmonically symmetric arcs; computed numerically, and the authors state that no rigorous error analysis was done. |
| $0.65628589^\*$ | <a href="#vS2026">[vS2026]</a> | Disc of radius $R=5.001117628756668$ minus 24 slits $z=\exp w$, $w=\log R+s+i(\theta+b\_1s^2+b\_2s^4)$, $\log(t/R)\le s\le 0$, with $(\theta,t,b\_1,b\_2)$ equal to $(0,1,0,0)$, $(\pi/3,1.9999999974092333,0,0)$, $(0.029930188727091613,2.789342409403121,0.9026921410641155,-0.3301459494660587)$, $(1.0157094972537686,3.473381248030611,-1.2656124700253997,0.9794269477754911)$, $(0.5757776442359243,4.342874184977691,0.03225521024585182,2.9360081049550737)$, and their images under rotation by $2\pi/3$ and complex conjugation. Computer-assisted proof: inradius $\le 1+10^{-9}$ (exact covering), conformal radius $\ge 1.523726208329$ (comparison function, Arb ball arithmetic). Floating-point value of the ratio $0.656285866$. |
| $0.6562681$ | <a href="#W2026">[W2026]</a> | Frank Wikström, Theorems 1.3 and 7.3: strict upper bound for the same univalent Bloch–Landau constant. The explicit domain has inradius divided by conformal radius less than $0.656268014$; exact curve data, an Arb capacity estimate and an inradius covering certificate. |

## Known lower bounds

| Bound | Reference | Comments |
| ----- | --------- | -------- |
| $\dfrac{1}{2}+10^{-335}$ | <a href="#Yan1995">[Yan1995]</a> | Follows from $L\le B_u$ together with Yanagihara's lower bound for $L$ as summarized in <a href="#BS2023">[BS2023]</a>. <a href="#BS2023-relations">[BS2023-relations]</a> <a href="#BS2023-bounds-L">[BS2023-bounds-L]</a> |
| $0.5708858$ | <a href="#Skin2009">[Skin2009]</a> | Earlier lower bound (as summarized in <a href="#BS2023">[BS2023]</a>). <a href="#BS2023-latest-Bu-lb">[BS2023-latest-Bu-lb]</a> |
| $\dfrac{306121}{500000}=0.612242$ | <a href="#W2026">[W2026]</a> | Frank Wikström, Theorem 1.2; finite interval certificate (Lemma 6.1). Applies to normalized univalent functions with $a\_2=0$ and $\lvert a\_3\rvert\leq 1/3$; Landau normalization gives the bound for $C\_{57c}$. |
| $\dfrac{6123}{10000}=0.61230^\*$ | <a href="#P2026">[P2026]</a> | Candidate, unrefereed; AI agents under Ricardo Pinho's direction, extending Wikström's framework, center (9) and phase congruence (12). A localized sixth-coefficient center term, higher Grunsky forms, area and Bloch constraints give a 489,994-leaf dyadic certificate in 12 parts; Arb at 192 bits. Exact gain $29/500000=0.000058$ over Wikström. Separately written checker by the same agent; no human referee. |
