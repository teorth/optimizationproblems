# A Sidon set constant

## Description of constant

$C_{5a}$ is the smallest constant such that Sidon sets in $\\{1,\dots,N\\}$ have cardinality $N^{1/2} + (C_{5a} + o(1))N^{1/4}$.

The fully explicit bound valid for every $k \ge 1$ is $\lvert\mathcal{A}\rvert \le N^{1/2} + 0.945\,N^{1/4} + 0.447$; since $C\_{5a}$ is asymptotic, the large-$k$ constant is the one recorded. |

## Additional comments and links

- **On the constant attributed to [CHO25].** [COT26, §1] cites that paper as giving $\mathrm{diam}(\mathcal{A}) \ge k^2 - 1.98183\,k^{3/2} - O(k)$, which would correspond to $C\_{5a} \le 0.990915$. The figure recorded above is [CHO25]'s own: its abstract states $b \le 1.96365$ and, equivalently, $n^{1/2} + 0.98183\,n^{1/4} + O(1)$, and $1.96365/2 = 0.981825$. [HZ26] also describes $0.98183$ as the previously published coefficient. The $1.98183$ appears to be a slip in [COT26]; nothing else depends on it.
- **A barrier for the smoothing method, not a lower bound on $C\_{5a}$.** [Akw26] argues that every certificate of the [HZ26] vector-valued smoothing framework, symmetric or two-sided, has $\gamma \ge 2\sqrt{2}/3 = 0.9428090415\dots$, and that the symmetric framework attains it; the same value is reported for a pair-level moment relaxation and a three-point relaxation. If correct this caps the method about $5\times 10^{-7}$ below the $0.9428095$ row, and it does **not** bound $C\_{5a}$ from below — a different argument could go under it. The lower bound recorded on this page remains $0$ [Si38]. None of these barrier proofs has been refereed.
- This is part of [Erdős problem #30](https://www.erdosproblems.com/30).
- A survey of the literature can be found at [OBO4].
