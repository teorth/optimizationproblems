# Schrijver–Seymour–Winkler ring loading constant

## Description of constant

$C\_{91}$ is the infimum of all $\alpha$ such that the following holds: for every $m \geq 1$ and all reals $u\_i, v\_i \geq 0$ with $u\_i + v\_i \leq 1$ ($1 \leq i \leq m$), there exist $z\_i \in \\{v\_i, -u\_i\\}$ with

$$\Big| \sum\_{i \leq k} z\_i - \sum\_{i > k} z\_i \Big| \leq \alpha \quad \text{for every } k.$$

This is the constant $\beta$ of Schrijver, Seymour and Winkler [SSW1998]. It arises from the ring loading problem, which compares the optimal unsplittable load $L$ with the optimal split load $L^\*$ in units of the maximum demand $D$ [SSW1998, S2016]. It is Problem 61 in the AlphaEvolve problem repository [GGSTW2025].

## Known lower bounds

| Bound | Reference | Comments |
| ----- | --------- | -------- |
| $101/100$ | [SSW1998] | |
| $11/10$ | [S2016] | Conjectured tight in [S2016] |
| $1.11905$ ($\approx 47/42$) | [GGSTW2025] | AlphaEvolve construction |
| $9/8$* | [N2026] | Explicit instance with $m = 15$, all entries multiples of $1/16$; verified by exhaustive search over all $2^{15}$ sign vectors in exact integer arithmetic (two independent checkers). Unrefereed; not yet independently replayed. |

## Additional comments

- The same instance gives a ring with 30 nodes and 55 demands whose unsplittable optimum is exactly $L^\* + \tfrac{9}{8} D$ ($L^\* = 15/2$, $L = 69/8$, $D = 1$), so no bound $L \leq L^\* + \alpha D$ with $\alpha < 9/8$ holds for ring loading itself [N2026].
- For ring loading itself, Däubel (2019) proves $L \leq L^\* + \tfrac{13}{10} D$.
