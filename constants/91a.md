# Average edit distance between two random binary strings

## Description of constant

Let $e\_n$ be the expected edit distance (the least number of single-letter insertions, deletions and substitutions turning one string into the other) between two independent uniformly random binary strings of length $n$.
Then $C\_{91} := \lim\_{n \to \infty} e\_n/n$; the limit exists by subadditivity, and $C\_{91} \leq e\_n/n$ for every $n$.

## Known upper bounds

| Bound | Reference | Comments |
| ----- | --------- | -------- |
| $1/2$ | Trivial | The expected Hamming distance |
| $0.36932$ | [BS2026] | Computer assisted: the exact value of $e\_{24}/24$ (Table 7 of the paper) |
| $0.315514$ | [R2024] | Computer assisted: Lueker's technique [L2009] adapted to the edit distance, with $h=17$ |

## Known lower bounds

| Bound | Reference | Comments |
| ----- | --------- | -------- |
| $0.162377$ | [D1994] | From $C\_{91} \geq 1 - C\_{31a}$ and Dančík's $C\_{31a} \leq 0.837623$, as tabulated in [BS2026], Table 1 |
| $0.17372$ | [L2009] | From $C\_{91} \geq 1 - C\_{31a}$ and $C\_{31a} \leq 0.826280$ |
| $0.157761$ | [GMR2016] | Volume argument; value computed in [BS2026], Table 1 |
| $0.170552$ | [BS2026] | Computer assisted |
| $0.178037$* | [T2026] | From $C\_{91} \geq 1 - C\_{31a}$ and $C\_{31a} \leq 0.821963$, which [T2026] proves with a Lean 4 formalization |
| $0.216276$* | [J2026] | First-moment count of canonical optimal alignments (alignments obeying five local rules that every pair of strings satisfies with some optimal alignment), done exactly with a transfer matrix; exact rational certificate (rational $x$, $t$ and a positive vector $v$ with $Av < v$) and a matrix-free check, both in the linked repository. |

## Additional comments

- Bilardi and Schimd estimate $C\_{91} \approx 0.27496$ by Monte Carlo at $n = 2^{15}$, with $0.999$-confidence interval $[0.26108, 0.28884]$ [BS2026, Table 6].
- $C\_{91} \geq 1 - C\_{31a}$ (with $C\_{31a}$ the [binary Chvátal–Sankoff constant](https://teorth.github.io/optimizationproblems/constants/31a.html)), since an alignment with $m$ matches costs at least $n - m$; the [D1994], [L2009] and [T2026] rows come from this.
- The same constant for $k$-letter alphabets is studied in [R2024], [BS2026] and [J2026]; [J2026] gives lower bounds for $k = 2, \dots, 8, 16, 32$, for example $0.424710$* for $k = 4$ (previously $0.359783$ [BS2026]).
