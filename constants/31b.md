# Chvátal–Sankoff constant for a four-letter alphabet

## Description of constant

Let $\lambda\_{n,4}$ be the random variable assigning two independent uniformly random strings of length $n$ over a four-letter alphabet the length of their longest common subsequence.
Then $C\_{31b}$ is the (well-defined) limit $C\_{31b} := \lim\_{n \to \infty}\frac{\mathbb{E}[\lambda\_{n,4}]}{n}$.
Four letters is the size of the DNA alphabet. The binary case is [$C\_{31a}$](https://teorth.github.io/optimizationproblems/constants/31a.html).

## Known upper bounds

| Bound | Reference | Comments |
| ----- | --------- | -------- |
| $1$ | Trivial | |
| $0.77291$ | [CS1975] | As tabulated in [D1994], Figure 4.2 |
| $0.708236$ | [D1994] | Computer assisted (Figure 4.6 of the thesis) |
| $0.683622$* | [J2026a] | Computer assisted. Lueker's automaton $M\_h$ of [L2009] (Section 3.2), run for four letters with $h=5$ (290,442 states); certificate with directed rounding. |
| $0.679701$* | [J2026a] | Same method with $h=6$ (8,502,177 states, $z=0.1570$); the transition table is built and read from disk. |

## Known lower bounds

| Bound | Reference | Comments |
| ----- | --------- | -------- |
| $1/4$ | Trivial | A common subsequence that uses a single letter |
| $0.545454$ | [D1994] | Analysis of Deken's matching algorithm (Section 3.5 of the thesis) |
| $0.599248$ | [KS2009] | Computer assisted (Lueker's lower-bound method) |
| $0.614333$ | [H2024] | Computer assisted, $h=8$ |
| $0.61422$ | [R2024] | Computer assisted, $h=8$ |
| $0.617356$* | [J2026b] | Computer assisted. Lueker's lower-bound method [L2009, Section 2] with $h=9$, storing one value per class of string pairs under alphabet permutations and swapping (1,431,743,147 classes); fixed-point certificate with every division rounded down, checked by an independently written checker. |
